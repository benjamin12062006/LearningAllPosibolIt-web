## Interpretación y límites

- La URL completa para Merchant Center es el origen de la API más `deliveryUrl`. En local será `http://127.0.0.1:8080/feeds/…`, que Merchant Center no alcanza: la prueba real exige la API publicada (R2).
- Como el token solo llega una vez, la web debe mostrarlo con claridad y ofrecer copiarlo; después solo puede ofrecer rotarlo.
- No hay listado de exportaciones: se publica desde la evaluación exportada o se vuelve a una versión del historial (que guarda su `exportId`).
- Las cifras de la política las decide el operador con el piloto: la web no propone valores por defecto «buenos».
