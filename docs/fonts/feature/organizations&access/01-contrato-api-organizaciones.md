## Interpretación y límites

- Con E1.2 retirada (O3), ver un proyecto de la organización no basta para abrirlo: `GET /projects/:id` sigue siendo del propietario. La web lista los proyectos de la organización (O6) y solo enlaza los que también están en tu lista de proyectos.
- La API no envía correos: la invitación es un enlace que la persona que invita comparte. Aceptarla exige entrar con el mismo correo invitado (O8).
- Los permisos llegan calculados (`access.permissions`); la web los usa para mostrar u ocultar acciones, pero la API decide (403).
- La organización elegida no cambia aún qué proyectos ves: eso sería E1.2.
