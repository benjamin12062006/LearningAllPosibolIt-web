## Evidencia

- **D1:** `UForm` acepta cualquier esquema Standard Schema; Zod 4 lo implementa. El formulario valida por campo y emite `submit` solo con datos válidos. `UFileUpload` admite `accept` y un solo archivo. `UDashboardGroup` recuerda el tamaño del lateral con `storage` y `storageKey`, como en F4 del curso.
- **D2:** el tema de Nuxt UI se ajusta sobrescribiendo sus variables después de los imports; `app.config.ts` elige `primary` y `neutral`.
- **D3:** lateral gris violáceo (~¼ del ancho) con tarjetas resumen y listas con contador; panel principal ciruela oscuro; cabecera ilustrada multicolor; título grande y fino; filas densas con un círculo a la izquierda y separadores tenues; acento violeta.
- **D4:** Copilot ya resolvió la traducción de D3 a Nuxt UI 4.12.0 en el mismo stack (Nuxt 4.6.2, Descope sustituido allí por Clerk). Sus colores salen de medir la captura.

## Interpretación y límites

- D2 no se volvió a descargar hoy: se usa la ficha de Copilot como fuente secundaria y se contrastó con los tipos instalados (D1), que son la evidencia directa de la versión usada.
- D3 es una referencia visual de otra app; no se copian sus recursos ni se añaden calendario, etiquetas de colores o temporizador que esta app no necesita. Los semáforos de ventana de macOS no se dibujan en el navegador.
- D4 es código propio de otro proyecto con otra API y otro proveedor de identidad. Se adaptan tokens y estructura visual; la carga de datos y los contratos se escriben para esta API.
